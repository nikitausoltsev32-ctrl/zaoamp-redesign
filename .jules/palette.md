## 2024-05-30 - Unlinked Labels Accessibility Pattern
**Learning:** React component forms in this codebase frequently use nested input structures inside `<label>` elements without explicitly declaring `htmlFor` and `id`. While nesting provides a basic implicit association for some screen readers, explicit linkage using `htmlFor` on the `<label>` and a matching `id` on the `<input>` provides the most robust accessibility support across all assistive technologies and allows for the label text to be clickable. Additionally, when fixing this, care must be taken to not introduce duplicated DOM IDs when fixing multiple standalone UI components, so ID prefixes (like `cta-` and `hero-`) should be used.
**Action:** Always verify explicit `htmlFor` and `id` linking for form fields in new or modified components, and utilize descriptive component prefixes or `useId()` to prevent global namespace ID collisions.
