# AI-менеджер сайта

AI-менеджер работает как подборщик продукта и сборщик заявок:

- отвечает в плавающем чате на сайте;
- использует Groq как основной LLM-провайдер;
- использует Gemini как fallback, если Groq недоступен;
- использует локальную базу знаний сайта: весь каталог, фракции, цены, упаковку, документы, применения и географию поставок;
- может читать прямые внешние URL из сообщения клиента;
- может выполнять web-поиск через Tavily или Brave Search, если добавлен API-ключ;
- сохраняет интересы, телефон, город, продукт, объем и историю диалога в Supabase;
- показывает собранные заявки на странице `/admin/ai-leads`.

## Переменные окружения

Не коммитить реальные ключи в GitHub. На Vercel или локально добавить:

```bash
GROQ_API_KEY=...
GROQ_MODEL=llama-3.3-70b-versatile

GEMINI_API_KEY=...
GEMINI_MODEL=gemini-2.5-flash

# Опционально: интернет-поиск для актуальной внешней информации.
# Достаточно одного из ключей. Без них агент отвечает по каталогу и может читать только прямые URL.
TAVILY_API_KEY=...
BRAVE_SEARCH_API_KEY=...

ADMIN_TOKEN=long-random-admin-password

NEXT_PUBLIC_SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
```

`GROQ_MODEL` и `GEMINI_MODEL` можно не задавать: в коде есть дефолты.

## База данных

Применить миграцию:

```bash
supabase db push
```

Миграция создает таблицу `public.ai_assistant_leads`. RLS включен, публичных политик нет. Запись и чтение идут только через серверный `SUPABASE_SERVICE_ROLE_KEY`.

## Админка

Открыть:

```text
/admin/ai-leads
```

Ввести значение `ADMIN_TOKEN`. Страница загружает последние 100 диалогов и показывает телефон, город, продукт, объем, упаковку, задачу и резюме.

## Ограничения

AI не должен обещать точные остатки, точную доставку или финальную цену. Он собирает данные и передает менеджеру для подтверждения условий.

Если `TAVILY_API_KEY` или `BRAVE_SEARCH_API_KEY` не настроены, агент честно сообщает, что полноценный интернет-поиск не подключен. При этом он все равно использует каталог сайта и может прочитать публичную страницу, если клиент прямо отправил URL.
