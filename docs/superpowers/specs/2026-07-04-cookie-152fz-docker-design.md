# Куки-баннер, 152-ФЗ, Docker-деплой на reg.ru VPS

Дата: 2026-07-04. Статус: утверждено.

## Проблема

- Метрика (108746641, webvisor) грузится всем без согласия — куки до согласия.
- Формы ссылаются на «политику конфиденциальности», страницы нет.
- Хостинг переезжает с Vercel на reg.ru VPS (Docker).

## Решение

### 152-ФЗ

1. **`/privacy/`** — политика обработки ПДн. Оператор: ЗАО «АМП ИМПОРТ-ЭКСПОРТ»,
   620144, Екатеринбург, ул. Евгения Савкова 29, оф. 262, evoprod@mail.ru
   (ИНН/ОГРН — добавить позже). Разделы: данные (имя, телефон, email, город,
   сообщение), куки/метрика, цели, основание (согласие), сроки, права субъекта,
   отзыв согласия. В sitemap. Ссылки: футер + тексты под формами.
2. **Куки-баннер** — строгий режим:
   - «Принять» / «Отклонить» + ссылка на политику; выбор в localStorage на 365 дней.
   - Метрика монтируется только после «Принять». Отказ/нет выбора — не грузится вообще.
   - Скрипт Метрики переезжает из `app/layout.tsx` в клиентский компонент.

### Docker (reg.ru VPS)

- `next.config.js`: `output: 'standalone'`.
- `Dockerfile`: multi-stage node:20-alpine (deps → build → runner).
- `docker-compose.yml`: `app` + `caddy` (80/443, авто-LE, volume сертификатов).
- `Caddyfile`: `amp-minerals.ru → reverse_proxy app:3000`.
- `.dockerignore`, `.env.example` (Telegram, Resend, Dellin, Groq/Gemini, Tavily, RESEND_FROM).
- `docs/DEPLOY.md`: DNS → Docker → .env → `docker compose up -d`.

## Решения по спорным местам

- Чекбокс согласия в формах не добавляем — остаётся текст-согласие со ссылкой
  на /privacy/ (конклюдентное действие), меньше трения.
- При отказе Метрика не грузится даже без куков (вариант «серая зона» отклонён).
- HTTPS терминирует Caddy (не nginx/certbot, не панель reg.ru).
