# Project: amp-minerals.ru (ЗАО АМП Импорт-Экспорт)

Сайт производителя белой мраморной крошки, щебня и микрокальцита. Next.js (App Router, TS).

## Позиционирование — главный SEO-принцип

**Усиливать сайт как «производитель с собственным карьером», а не перекупщик/поставщик.**

Это подтверждено реальными данными Яндекс.Вебмастера (2026-06-27): клики из поиска идут на
брендовые запросы + небрендовые с интентом «карьер/производитель»:
- `карьер мраморной крошки` — 1 показ, 1 клик
- `белый мраморный щебень карьер в челябинской области` — 1 показ, 1 клик
- `амп минералс`, `мраморная крошка амп минералс`, `зао амп импорт` — брендовые, конвертят

Клиенты, которые звонят/кликают, ищут именно производителя и карьер, а не перекупа.

**Как применять** в title, H1, meta, seoContent, schema:
- Подчёркивать: собственный карьер белого мрамора (Челябинская обл.), работа с 2004 (20+ лет),
  паспорта качества на каждую партию, отгрузка навалом/биг-бэг/мешки, доставка по РФ/РБ/РК.
- Использовать слова «карьер», «производитель», «собственное месторождение», «завод».
- Числа спецификаций — только из паспортов (`memory/product_specs.md`), не выдумывать.

## Сайт — источник истины

При конфликте офсайт-контента (Дзен/VC) или конспектов с позиционированием **сайта** — всегда
выравнивать под сайт. Пример: мраморный щебень сайт позиционирует для бетона/ЖБИ/дорожных
оснований/тротуарной плитки + благоустройства — не писать «не для несущих слоёв, нужен гранит».

Паспортные марки (дробимость М200, истираемость И4, морозостойкость F50, лещадность I группа ~6%)
указаны «в среднем по месторождению» → применимы к любой фракции, включая щебень. Можно
приводить для щебня. См. [[product_specs]].
