### llms.txt
**Статус: ✗ ОТСУТСТВУЕТ — Критическая проблема**

Файл `/llms.txt` возвращает 404. Для B2B поставщика промышленных материалов это упущенная возможность дать AI-системам структурированный контекст о компании, продуктах и экспертизе.

**Что должно быть в llms.txt:**
```
# ЗАО АМП ИМПОРТ-ЭКСПОРТ

> Производитель мраморного щебня, крошки и микрокальцита с собственным карьером в Челябинской области. Поставки по России, Беларуси, Казахстану с 2004 года.

## Продукция
- Мраморный щебень: фракции 10-20, 20-50, 50-200 мм. CaCO₃ ≥98%, белизна 98%, Класс радиации I
- Мраморная крошка: 8 фракций от 0-1 до 5-10 мм
- Мука и микрокальцит: 0-0,2 мм, 5-200 мкм

## Применения
Ландшафтный дизайн, дорожное строительство, штукатурные смеси, ЛКМ, сельское хозяйство

## Паспорта качества
https://amp-minerals.ru/documents/

## Каталог
https://amp-minerals.ru/catalog/
```

## Технические детали для разработчика

### Как внедрить JSON-LD в Next.js

В `app/layout.tsx` (глобальная Organization schema):
```tsx
export default function RootLayout({ children }) {
  const orgSchema = {
    "@context": "https://schema.org",
    // ... (см. блок Organization выше)
  }
  return (
    <html lang="ru">
      <head>
        <script
          type="application/ld+json"
          dangerouslySetInnerHTML={{ __html: JSON.stringify(orgSchema) }}
        />
      </head>
      <body>{children}</body>
    </html>
  )
}
```

На каждой продуктовой странице — отдельный `<script type="application/ld+json">` с Product + BreadcrumbList.  
На категорийных страницах — FAQPage schema.  
В блоге — Article schema с author.
