## 1. Индексация

### Что удалось проверить

| Поисковик | Статус | Чем подтверждено |
|---|---|---|
| **Яндекс** | **В индексе** | TopVisor 25.08.2026: «амп минералс» → позиция 1, `relevant_url = https://amp-minerals.ru/`; «amp-minerals» → позиция 1, `relevant_url = https://amp-minerals.ru/moskva/`; «мраморная мука купить» → 69, `/catalog/muka/`; «производитель мраморного щебня» → 91, `/`. Четыре разных URL определены как релевантные — значит в индексе минимум они |
| **Bing** | **В индексе** | Проверка через DuckDuckGo (работает на индексе Bing), запрос `site:amp-minerals.ru` отдал: `/`, `/about/`, `/catalog/`, `/catalog/shcheben/`, `/contacts/`, `/moskva/`, `/primenenie/`, `/product/mramornaya-kroshka-0-1/`, `/product/mramornaya-kroshka-0-5-1-0/`, `/product/mramornaya-muka-0-0-2/` — 10 URL на первой странице |
| **Google** | **Не установлено** | TopVisor: 0 позиций по всем 33 запросам, включая брендовые. Прямой запрос `site:amp-minerals.ru` к google.com → `302` (антибот). API Search Console недоступен без OAuth |

### Технических препятствий для индексации нет

Проверено:

- `noindex` / `nofollow` — **не встречается нигде** в `app/`, `lib/`, `components/`
  (grep по всему коду, 0 совпадений).
- `meta robots` на всех 40 страницах: `index, follow`.
- `meta googlebot`: `index, follow, max-video-preview:-1, max-image-preview:large, max-snippet:-1`.
- robots.txt: `Allow: /`, закрыт только `/api/`. Googlebot и bingbot прописаны явно.
- Все 40 URL из sitemap отдают **200**.
- Маршруты в `app/` полностью соответствуют sitemap — потерянных страниц нет
  (16 роутов, из них 4 динамических, разворачиваются в 13 товаров + 5 городов +
  5 применений + 5 статей = 40 URL).
- Канонические адреса self-referencing на всех страницах.
- Верификации обоих поисковиков стоят в `<head>`.

**Вывод: сайт не заблокирован. Если в Google его нет — причина не в настройках сайта,
а либо в неотработавшей проверке TopVisor, либо в том, что Google просто не выбрал
страницы для индексирования (типично для нового домена без внешних ссылок).**

### Чего не хватает

- **IndexNow не настроен.** Ключа в `public/` нет, `indexnow_submit.py` не использовался.
  IndexNow поддерживают Bing и Яндекс — это бесплатный мгновенный пинг об обновлениях.
- Пинг sitemap после деплоя не автоматизирован.

### Что сделать (по приоритету)

1. **Яндекс.Вебмастер, вручную, сегодня:** «Индексирование → Страницы в поиске» —
   сколько страниц в поиске из 40, что в «Исключённых» и с какой причиной.
   Там же «Диагностика» и, главное, **«Региональность»** — присвоен ли сайту регион.
2. **Google Search Console, вручную, сегодня:** «Индексирование → Страницы» (покрытие) и
   «Результаты поиска» за 3 месяца. Если показов 0 при 40 страницах в индексе — проблема
   не в индексации, а в ранжировании. Если страниц в индексе 0–3 — нужен запрос на
   индексирование по приоритетным URL.
3. Настроить IndexNow: ключ в `public/<key>.txt` + отправка при деплое.
4. Отправить sitemap в оба Вебмастера повторно.

## 2. Ссылочный профиль — ИЗМЕРЕНО

Источник: **Yandex Webmaster API v4**, `links/external/history` и `links/external/samples`,
выгружено 12.09.2026 (`findings/yandex-links.json`). Это данные самого Яндекса, не оценка.

### Всего внешних ссылок: 4

```
2026-05-01 -> 0
2026-05-24 -> 0
2026-06-05 -> 1
2026-07-14 -> 3
2026-09-06 -> 4
```

### Все четыре ссылки

| Источник | Что это |
|---|---|
| `yandex.ru/maps/org/amp_import_eksport/170350594774/` | карточка в Яндекс.Картах |
| `yandex.com.tr/maps/org/amp_import_eksport/170350594774/?lang=ru` | **то же самое**, турецкое зеркало Карт |
| `yandex.com/maps/org/amp_import_eksport/170350594774/` | **то же самое**, международное зеркало Карт |
| `shortenurls.eu/share/133587` | сокращатель ссылок, не упоминание компании |

**Уникальных доноров фактически два**, и один из них — сокращатель. Три из четырёх ссылок —
это зеркала одной и той же карточки в Картах.

### Что это означает

Ссылочного профиля у сайта нет. Не «мало ссылок» — их нет вообще, кроме собственной
карточки в Картах. Это и есть ответ на главный вопрос аудита: разрыв между 71/100
технического здоровья и 29 коммерческими запросами вне top-100 закрывается именно здесь.

Никакая доработка title, схемы или контента не выведет сайт в конкурентную выдачу по
«мраморная крошка купить», пока внешних сигналов ноль. Техническая часть аудита при этом
не бесполезна — она убирает препятствия, но она не источник роста.

Предыдущая формулировка про Common Crawl («домена нет в графе») снята как недостоверная:
скрипт на этой машине не завершается, и его ответ был неотличим от недокачанного датасета.
Данные Вебмастера её подтвердили, но опираться теперь нужно на них.

### Дополнительно: главное зеркало не задано

В выгрузке `hosts` у `https://amp-minerals.ru/` стоит `main_mirror: null`, и хост `www`
в Вебмастере вообще не добавлен. Вместе с тем, что `www.amp-minerals.ru` отдаёт **200**
вместо 301 (см. Technical SEO), это реальный риск склейки: Яндекс может считать www
отдельным непроверенным хостом. Задать главное зеркало в Вебмастере — обязательный шаг
вместе с 301 на уровне Caddy.

### Что осталось неизмеренным

| Данные | Источник | Статус |
|---|---|---|
| Анкор-лист | Яндекс отдаёт только URL-пары | нужен Bing Webmaster API или Moz |
| DA / PA / спам-скор | Moz API (free 2500/мес) | нет ключа |
| Ссылочное конкурентов | Moz / Bing | нет ключей |
| Ссылки по версии Google | GSC API | нет OAuth |

Для приоритизации это уже не критично: при четырёх ссылках сравнение с конкурентами
ничего не изменит в плане работ. Ключи нужны, чтобы потом измерять прогресс.

### План по ссылочному

Фаза А — бесплатные и законные размещения (1–2 недели, делается один раз):

1. **ЕГРЮЛ-агрегаторы.** Rusprofile, List-org, Audit-it, Sbis — карточки создаются
   автоматически по ИНН, но ссылку на сайт и описание нужно заявить. Это самые
   «доверенные» с точки зрения Яндекса упоминания для юрлица.
2. **Яндекс Бизнес.** Карточка в Картах есть, но нужно проверить: заполнены ли категории,
   есть ли фото производства, товары, часы, и — главное — **добавить филиалы/зоны
   обслуживания по регионам поставки**. Это напрямую влияет на геовыдачу.
3. **2ГИС** — отдельная карточка, отдельный трафик, для Урала особенно.
4. **Отраслевые каталоги нерудных материалов и стройматериалов** — Пульс цен, Тендер-Юг,
   Все Строй Материалы, региональные B2B-справочники. Только те, где регистрация
   реальная, а не ссылочные помойки.
5. **Дзен и VC.** Контент уже есть — в каждой публикации ссылка на релевантную страницу
   сайта, а не только на главную.
6. **Профили в ЕИС/Закупках**, если компания участвует — там появляются упоминания
   с сильных доменов.

Фаза Б — заработанные ссылки (постоянно):

7. **Паспорта качества как инфоповод.** Разбор «что означает I класс радиоактивности»
   уже есть в блоге — такие материалы цитируют строительные порталы. Нужны питчи, а не
   ожидание.
8. **Кейсы объектов.** Как только появятся фото отгрузок (см. фазу 1 основного плана),
   из каждого объекта делается кейс — их охотно берут ландшафтные и строительные медиа.
9. **Карьер как уникальный контент.** Собственное месторождение белого мрамора в
   Челябинской области — это редкость. Материал с фото и цифрами с производства даёт
   естественные ссылки, чего не даст ни один текст про «фракции и применение».

Важно: фаза А осмысленна сама по себе — карточки в Яндекс Бизнес, 2ГИС и ЕГРЮЛ-агрегаторах
нужны любому производителю независимо от того, что покажет замер ссылочного. Так что её
можно начинать не дожидаясь ключей.

Чего **не** делать: покупных ссылок с сеток, прогонов по каталогам, комментарийного спама.
На молодом домене резкий приток покупных ссылок — прямой путь под фильтр Яндекса.

## 3. Полевые Core Web Vitals

### Статус: не получены

Безключевой PageSpeed Insights v5 **больше не работает**. Проверил на трёх URL в двух
стратегиях — все шесть запросов вернули:

```
HTTP 429  RESOURCE_EXHAUSTED
"Quota exceeded for quota metric 'Queries' and limit 'Queries per day'"
quota_limit_value: "0"
```

То есть квота без ключа обнулена. CrUX API тоже требует ключ. Playwright MCP не поднялся,
Chrome-расширение не подключено — лабораторный замер в реальном браузере тоже недоступен.

### Что измерено на стороне сервера (это не CWV, но полезно)

| URL | TTFB | Total | HTML | gzip |
|---|---|---|---|---|
| `/` | 116 мс | 161 мс | 181 КБ | 31 КБ |
| `/catalog/kroshka/` | 70 мс | 98 мс | 132 КБ | — |
| `/product/mramornyj-shheben-10-20/` | 67 мс | 95 мс | 124 КБ | — |
| `/moskva/` | 69 мс | 98 мс | 147 КБ | — |

`x-nextjs-cache: HIT` на всех. Сервер быстрый, ISR работает.

JS+CSS: **826 КБ несжатого в 20 чанках**, крупнейшие 172 / 119 / 112 / 68 / 59 КБ,
плюс `polyfills` 91 КБ и CSS 56 КБ. Это главный кандидат на проблемы с INP на мобильных —
но подтвердить можно только полевыми данными.

LCP-цепочка построена правильно: `fetchPriority="high"`, `<link rel="preload" as="image">`
с полным `imageSrcSet`, WebP, `sizes="100vw"`, шрифты self-hosted woff2 с preload.
Все `fill`-картинки с явными размерами — CLS защищён на уровне разметки.

### Что нужно

`GOOGLE_API_KEY` (бесплатный, минута) → CrUX API отдаст реальные LCP / INP / CLS по
75-му перцентилю, отдельно mobile и desktop, плюс историю за 6 месяцев через CrUX History.

Оговорка: CrUX отдаёт данные только при достаточном трафике на домен. При текущей
органике (почти нулевой) домен может оказаться в статусе «недостаточно данных» — тогда
останется только лабораторный замер через PSI, который тот же ключ и открывает.

## 4. Что меняется в оценке аудита

Оценки категорий из `FULL-AUDIT-REPORT.md` не пересчитываю: новые данные не про сайт,
а про его окружение. Но главный вывод усиливается и становится доказанным, а не
предполагаемым:

> Сайт технически здоров (71/100), в индексе Яндекса и Bing, без блокировок и без
> `noindex`. Технических причин отсутствия в выдаче нет.
> **Внешних ссылок — 4, из них уникальных доноров два, и один из них сокращатель ссылок**
> (данные Yandex Webmaster API). Вот и вся причина 29 запросов вне top-100.

Порядок работ меняется: **фаза A (внешние сигналы) становится приоритетом номер один**,
наравне с фазой 0. Раньше она стояла параллельно фазе 2 — теперь понятно, что она и есть
главная работа, а всё остальное убирает препятствия на её пути.

Фазы 0 и 1 при этом никуда не деваются: закупщик, который придёт по будущей ссылке, не
должен увидеть страницу доставки без H1 и пунктирные рамки вместо фото карьера.
