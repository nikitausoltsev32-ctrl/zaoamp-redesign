# Бриф: страницы применения и /catalog/kroshka/

Дата: 2026-09-27. Источники: `Seo/semantic/frequency-results.csv` (Wordstat, Яндекс, Россия, 23.09),
`Seo/data/2026-09-27/gsc-queries.json`, `yandex-events.json`. Частота — точная (в скобках общая).

## Главный вывод по семантике

Формулировки «… купить оптом» по SKU и категориям имеют **точную частоту 0**. Спрос сидит в
коротких и прикладных формулировках: «мраморная крошка» 2803, «цена» 96, «в мешках» 103,
«для фасада» 123, «для цоколя» 86, «в ландшафтном дизайне» 57. Title/H1 сейчас заточены под
«оптом» — это не то, что ищут. «Опт от 5 тонн» оставляем в тексте и условиях, но не в главном
ключе.

## Почему Яндекс исключает страницы применения (гипотеза)

Тексты на страницах есть (рекомендации, FAQ, SEO-блок, таблица) — это не «пустые» страницы.
LOW_QUALITY у Яндекса чаще означает «маловостребованная»: мало показов/кликов и нет данных о
поведении. Метрика до 27.09 не видела почти никого → Яндекс не получал сигналов. Плюс страницы
пересекаются с `/catalog/kroshka/` и блогом по тем же фракциям. Поэтому план — не «добавить
текста», а: точнее попасть в спрос, дать уникальное (объекты, фото, расчёт), развести с каталогом.

## 1. `/primenenie/landshaft/`

- **Главный запрос:** мраморная крошка в ландшафтном дизайне — 57 (201)
- **Поддерживающие:** купить мраморную крошку для ландшафтного дизайна 52 (163); для ландшафтного дизайна 30 (230); на клумбе 21 (124); для сада 14 (178); цветник из мраморной крошки 7 (112)
- **Сейчас:** title «…для ландшафтного дизайна - фракции и цена»; GSC 136 показов, поз. 29,7.
- **Предлагаю:**
  - title: «Мраморная крошка в ландшафтном дизайне — клумбы, дорожки, сад | АМП» (≤70)
  - H1 без изменений по смыслу, добавить «и сада».
  - Новые блоки: «Клумбы и цветники» (отдельный H2 — есть спрос 21+7), «Расчёт на участок» (формула уже есть: 60–65 кг/м² при 5 см — дать 2–3 примера площадей), «Фото с объектов» (**нужны фото от заказчика**).
  - Развести с `/catalog/kroshka/`: на странице — задачи ландшафта, на каталоге — фракции и условия.

## 2. `/primenenie/shtukaturka/`

- **Главный запрос:** мраморная крошка для фасада — 123 (904)
- **Поддерживающие:** для цоколя 86 (370); штукатурка мраморная крошка 74 (2128); штукатурка с мраморной крошкой для фасада 72; для цоколя 55; отделка цоколя 46; декоративная штукатурка 41 (527); для фасада купить 25
- **Сейчас:** title «Мраморная крошка для декоративной штукатурки оптом» — «фасад» и «цоколь» в title/H1 нет.
- **Предлагаю:**
  - title: «Мраморная крошка для фасада, цоколя и штукатурки — фракции | АМП»
  - H1: «Мраморная крошка для фасадной и цокольной штукатурки»
  - Новые H2: «Для фасада», «Для цоколя» (фракции, толщина слоя — **только если есть данные заказчика/паспорта**; иначе общее без цифр), «Для производителей сухих смесей» (B2B-хвост).

## 3. `/primenenie/lkm/` — нужно решение

- Прямой B2B-спрос почти нулевой: «микрокальцит для ЛКМ и пластиков» 0; «мраморная мука применение в лкм» 5; «акриловая краска с микрокальцитом» 5.
- Основной спрос — «краска с мраморной крошкой» 42 (867): это покупатели **готовой краски**, не сырья.
- Варианты:
  - **а)** Оставить страницу, переписать под производителей ЛКМ/пластика (узкий B2B, трафика будет мало, но лиды качественные); смириться, что Яндекс может держать её вне поиска.
  - **б)** Объединить с `/catalog/muka/` (микрокальцит): содержимое ЛКМ — разделом на категории, `/primenenie/lkm/` → 301 на `/catalog/muka/`. Одна сильная страница вместо двух слабых. **Рекомендую б.**

## 4. `/catalog/kroshka/`

- **Главный запрос:** мраморная крошка — 2803 (64 625); GSC поз. 6 по нему (1 показ), «мраморная крошка оптом» 66 показов, поз. 37,7.
- **Поддерживающие:** цена 96 (2994); в мешках 103 (2795); купить в мешках 87; где купить 90; оптом 39 (393); оптом от производителя 32; белая в мешках 25
- **Предлагаю:**
  - title: «Мраморная крошка от производителя: цена за тонну, мешки, биг-бэги» (≤70) (сейчас в title нет «цена» и «мешки»)
  - Блок «Цена»: без публичных цифр (решение 21.09) — «от чего зависит цена» + форма расчёта; для запроса «цена» это минимально достаточно.
  - Блок «Упаковка: мешки / биг-бэги / навал» — **нужно от заказчика: вес мешка (25 кг? 50 кг?)**, есть ли мешки по всем фракциям.
  - Акцент «собственный карьер, Челябинская обл., с 2004» — в H1/лиде (позиционирование проекта).

## 5. `/product/mramornaya-kroshka-5-10/`

- «мраморная крошка 5 10» 26 (532); «фракция 5 10» 20; GSC 206 показов, поз. 26, 0 кликов.
- Title/H1 добавить «5–10 мм» в естественной форме «мраморная крошка 5-10» + «фракция»; сниппет — белизна, упаковка, «от 5 т».

## Что нужно от заказчика

1. Фото с объектов: ландшафт (клумбы, дорожки), фасад/цоколь — хотя бы 3–5 снимков с подписью (город, объект).
2. Упаковка мешками: вес мешка, для каких фракций.
3. Для штукатурки: какие фракции реально берут производители смесей / фасадчики (если знаете клиентов — без имён).
4. Решение по ЛКМ: вариант а или б.

## Порядок внедрения

Title/H1/description (Ф5-01) → новые блоки с фактами → согласование текста → деплой →
переобход 4–5 URL → окно наблюдения 2–4 недели (Вебмастер: статус в поиске; GSC: позиции).
